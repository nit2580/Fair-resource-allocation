// SYSTEM OVERVIEW
Preventing Starvation
🛡
Anti-Starvation Guarantee
Every process is guaranteed CPU time. When a process waits beyond the starvation threshold, the system automatically boosts its priority to ensure forward progress.
📈
Dynamic Priority Adjustment
Process priorities are not static. The system continuously recalculates effective priorities based on wait time, burst behavior, and CPU usage history.
⚡
Maximized CPU Utilization
By keeping the ready queue optimally populated and minimizing idle cycles, FRAS ensures the CPU stays busy while maintaining per-process fairness guarantees.
🔍
Real-Time Observability
Every scheduling decision is logged with timestamps. The Gantt chart visualizes CPU allocation across time, making starvation events and boosts instantly visible.
